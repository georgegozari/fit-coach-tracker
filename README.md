# 減重追蹤 App

給教練和學員一起用的減重追蹤 App，手機優先，可以「加入主畫面」當成 App 使用。

- **學員每天回報**：空腹體重、安靜心率、步數、有氧分鐘、間歇分鐘、備註
- **教練設定目標**：碳水／蛋白質／脂肪（熱量自動計算）、每日步數、每週有氧、每週間歇，可以設定「從某天開始生效」，保留歷史
- **每週 InBody**：體重、骨骼肌量、體脂肪量、體脂率、內臟脂肪、基礎代謝、InBody 分數、腰圍
- **週報**：週平均體重與上週差異、心率、步數總計／日均、運動達標狀況、每日明細，一鍵複製貼到 LINE
- **趨勢圖**：每日體重 + 7 日平均、每週運動量 vs 目標、步數與心率、InBody 變化
- **權限**：教練金鑰可以改目標；學員金鑰只能回報每日資料和 InBody
- **匯出 CSV**

資料存在你自己的 Google 試算表裡，用 Google Apps Script 當後端，不需要任何付費服務。

## 架構

```
手機（GitHub Pages 上的網頁 App）
        │  fetch
        ▼
Google Apps Script 網頁應用程式（apps-script/Code.gs）
        │
        ▼
Google 試算表：Daily / Targets / InBody / Settings 四個工作表
```

## 後端設定（只要做一次，約 5 分鐘）

1. 打開資料用的 Google 試算表（已建立好的「Nash減肥App資料」，或自己新建一個）
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `apps-script/Code.gs` 全部內容貼上，取代原本的程式碼，按儲存
4. 上方函式選單選 **`setup`** → 按 **執行**，第一次會要求授權（選自己的帳號 → 進階 → 前往（不安全）→ 允許）
5. 打開下方 **執行記錄**，會看到「教練金鑰」和「學員金鑰」
6. 右上角 **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署，複製「網頁應用程式網址」（結尾是 `/exec`）
7. 打開 App → **設定** → 貼上網址和**教練金鑰** → 連線並同步
8. 在設定頁按 **複製學員連結**，傳給學員。學員打開後會自動連線，再用瀏覽器的「加入主畫面」即可

> 之後如果修改了 `Code.gs`，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 才會生效（網址不變）。
>
> 想換金鑰（例如連結外流），在 Apps Script 執行 `rotateKeys()`，再重新分享連結。

## 本機模式

沒有設定後端時，App 會以「本機模式」運作，資料只存在該裝置的瀏覽器，可以先試用。

## 開發

純 HTML / CSS / JS，不需要建置。本機測試：

```bash
python3 -m http.server 8000
```

打開 http://localhost:8000

| 檔案 | 用途 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 前端 App |
| `sw.js` / `manifest.json` / `icons/` | PWA（加入主畫面、離線開啟） |
| `apps-script/Code.gs` | Google Apps Script 後端 |

## 週的算法

每週從星期一開始，第 1 週是「計畫開始日」所在的那一週（在設定頁可改）。沒有任何回報的週不會出現在週報中，但週數仍照日期計算。
